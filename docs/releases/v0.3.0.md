**M-VAVE's new V16 firmware runs** (it froze with a blank screen in 0.2.0), M-VAVE's FM1 Open
boots and plays, and the x86-64 Linux build compiles firmware to native code. The page,
[joakimeriksson.github.io/fm1-emu](https://joakimeriksson.github.io/fm1-emu/), needs no download
and is always the latest.

## Downloads

| File | For |
|---|---|
| `fm1-plugin-0.3.0-macos-arm64.zip` | The plugin (AU, VST3, CLAP): Macs with Apple silicon, macOS 11 or later. Its `INSTALL.txt` says where each file goes. |
| `fm1-emu-0.3.0-macos-arm64.tar.gz` | fm1-live and fm1-emu, Macs with Apple silicon (with the JIT) |
| `fm1-emu-0.3.0-linux-arm64.tar.gz` | fm1-live and fm1-emu, 64-bit ARM Linux (with the JIT) |
| `fm1-emu-0.3.0-linux-x86_64.tar.gz` | fm1-live and fm1-emu, x86-64 Linux (with the JIT, new in this release) |

The JIT runs on Windows too when built from source; a Windows download is still to come.

**fm1-live** plays a firmware package: `./fm1-live --fwsc felucca.fwsc`. The packages: the
community firmwares on [the FM-1 Firmware Hub](https://thefirmwarehub.com/) (and the list on
the page, with each author's link), or M-VAVE's own `FM-1.fwsc`. The computer keyboard plays
the keys, and so does every MIDI input. On Linux it needs ALSA and X11:
`sudo apt install libasound2 libx11-6 libxkbcommon0 libxcursor1 libxrandr2 libxi6` (Ubuntu 24.04
and later: `libasound2t64` in place of `libasound2`). Each archive's `README.txt` has the rest.

**Not signed:** macOS blocks the downloads until you allow them. For the plugin, after copying
it (as `INSTALL.txt` says):

```sh
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/FM-1.component ~/Library/Audio/Plug-Ins/VST3/FM-1.vst3 ~/Library/Audio/Plug-Ins/CLAP/FM-1.clap
```

and for fm1-live, in its folder: `xattr -d com.apple.quarantine fm1-live fm1-emu`.

## What's new since 0.2.0

- **M-VAVE's firmware:** V16 boots, shows its screen and plays (#73: its patch storage, new FPU
  instructions and its LCD driver's interrupt). FM1 Open, M-VAVE's open firmware, boots and makes
  sound.
- **The plugin:** 120 and 160 MHz CPU clocks for heavy firmwares on slower computers; projects
  saved with 0.2.0 keep their clock.
- **The keys feel force:** where a key is pressed and how hard sets its velocity and pressure, for
  firmwares that sense them (CS-1, Velo, Scintilla and others).
- **Faster:** the JIT on x86-64 Linux; generated code stays in generated code longer (returns,
  RAM guards, predicated blocks, more ops compiled); polling loops skipped; FM1-DOOM +44%.
- **Fixes:** the JIT now plays exactly what the interpreter plays (run budgets to the
  instruction); code that writes into its own block; stale flags behind a jump; descending block
  moves; the second core's release latch; the global interrupt enable; several decoding fixes;
  the flash chip's encryption below its plain window.
- **For firmware authors:** USB in the emulator (`fm1-live --usb`: a host enumerates the
  firmware's USB-MIDI device); `--flash FILE` keeps the flash between runs, and
  `FM1_FLASH_CUT=N` cuts the power mid-write; the build's commit in `--version`; CI now checks
  every catalog firmware's audio, compiled and interpreted, against stored hashes.
